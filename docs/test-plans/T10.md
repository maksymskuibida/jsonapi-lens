# Test plan — T10 · The test suite must not depend on the runner's language

Verification is by running the suite under host locales other than this machine's, and by mutating
the guard to prove it guards. There is no observable surface, so there is no browser or QA pass —
see `docs/qa-notes/T10.md`.

| # | Scenario | Expected | How verified |
|---|---|---|---|
| 1 | The defect reproduces on `main` before the fix | `LC_ALL=de_DE.UTF-8` → 5 failures in `test/crypto.test.ts`, each answering in German | manual (recorded in the spec) |
| 2 | Whole suite under a German host locale | 618/618 | automated (vitest), run by hand per locale |
| 3 | Whole suite under a Ukrainian host locale | 618/618 | automated (vitest) |
| 4 | Whole suite under an English host locale | 618/618 | automated (vitest) |
| 5 | Whole suite under `LC_ALL=C` — what CI uses | 618/618. **Known flake, not locale-related:** `test/panels.test.ts`'s tab-deletion case failed once in four runs with an *empty* toast rather than a German one; it waits on a fixed 20 ms timer. Out of scope, named in the spec | automated (vitest) |
| 6 | The pin is load-bearing, not decorative | Pinning `"de"` instead of `"en"` turns the same 5 `crypto.test.ts` assertions red under `LC_ALL=C`; restoring gives 37/37 | mutation, by hand |
| 7 | Removing the pin block entirely | `test/locale-pin.test.ts` fails 4 of its 5 cases on an English machine — the fifth being the environment-independent control | mutation, by hand |
| 8 | `?lang=` still wins over the pin | `fromQuery()` is consulted before `stored()`, so a test exercising an explicit language is unaffected | automated (`test/locale-pin.test.ts`, `negotiateUnder(..., { pinned: false })`) |
| 9 | The pin survives a host that already defines `localStorage` | Overwritten, not merely tolerated | automated (`--pre-existing-de-storage`) |
| 10 | The pin survives a `localStorage` that throws, and one that silently no-ops | Pinned either way — the read-back is what catches the second | automated (`--throwing-storage`, `--noop-storage`) |
| 11 | `test/mcp/locale-pin.test.ts`'s positive control under a non-German runner `LC_ALL` | Passes. It drops `LC_ALL`, `LC_MESSAGES` and `LANGUAGE` from the child rather than merely setting `LANG`, because POSIX ranks `LC_ALL` above `LANG` | automated (vitest) |
| 12 | That control is not a tautology | Replacing the child's expression with a constant fails it loudly | mutation, by hand |
| 13 | Locale-variable precedence, as the fix assumes it | `LC_ALL` beats `LANG`; `LC_MESSAGES` beats `LANG`; `LANGUAGE` is ignored by ICU | manual, against a bare Node process |
