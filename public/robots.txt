# Three paths are worth reading and they are all static: the paste view, the
# Impressum and the privacy policy. Everything else is either a shell with no
# content of its own or somebody's document.
#
#   /view   the document view. Without a document in *your* browser's IndexedDB
#           it renders nothing, so a crawler would only ever index an empty page.
#   /d/…    a share link. The decryption key is part of the URL, so a crawler
#           that runs JavaScript could render a document somebody meant for one
#           recipient. Never index these. `_headers` says the same thing with an
#           `X-Robots-Tag`, because a Disallow is a request and a header is not.
#   /api/…  the share endpoint. JSON, and `no-store`.

User-agent: *
Allow: /
Disallow: /view
Disallow: /d/
Disallow: /api/
